## Lead decisions and exact interface
Use a separate conservative 400 m grid for cover, including cells without any buildings. A long road/polygon belongs in every cell intersecting its dequantized AABB, not a single centroid owner; later geometry clipping owns duplication. Preserve original numeric indices for each layer and full immutable CityData for downstream predicates. This index does not wrap/subset CityData.

Export CoverLayer = 'roads' | 'parks' | 'water'. Export CoverSelection { roads: readonly number[]; parks: readonly number[]; water: readonly number[] }. Export CoverIndex containing readonly cellSizeM: number, cells: ReadonlyMap<CellId, CoverSelection>, bounds per original layer record (readonly BoundsXZ arrays, for exact AABB filtering), and overall bounds: BoundsXZ | null. Use names featureBounds and bounds for these two fields. Grid cells are world-origin aligned with cellSizeM=400 (no public tuning parameter in this packet).
Export createCoverIndexJob({ id, generation, essential, cityData, now, sliceMs?=4, onReady(index: CoverIndex): void }): BuildJob.
Export coverForBounds(index: CoverIndex, bounds: BoundsXZ, padM=0): CoverSelection.

## Required behavior
1. Constructor validates sliceMs finite positive and stores cursors only; no record or point iteration and no geometry/all-array copies. Process layers in roads, parks, water order; each layer original indices ascending. Every step does at most 64 atomic units even with a constant clock, checking elapsed time between units. Each unit is ONE record setup/transition, ONE vertex-pair dequantization/AABB update, ONE bucket insertion, or ONE publication action. Never process a whole long feature or its bucket rectangle in one unit. At least one unit per active step to ensure progress, then stop if elapsed >= sliceMs.
2. Road pts must have even length >=4; polygon verts even length >=6. Reject malformed record when reached (RangeError including layer/index), do not eagerly validate all input. Use format dequantizeX/Y exactly. No triangle data needed. Source typed arrays must not be modified. Accumulate a feature AABB vertex-by-vertex; store a bounds entry in its original-index slot; walk the inclusive integer grid rectangle using resumable x/z cursors. Every bucket list is naturally original-index ordered, unique per layer. Do not perform whole-index sorting/copying/freezing at publication.
3. Complete index publication happens exactly once. This is a pure CPU index with no disposable GPU resources. Explicit publication ownership: mark terminal and detach local references BEFORE invoking onReady; never mutate the published map/arrays afterward, even if callback cancels or throws. Cancel before completion drops private state without iterating buffers/maps, never calls onReady, is idempotent, later step returns true. A thrown clock/input/callback error is preserved exactly (including falsy thrown values), terminal, and never retried by later steps. Reentrant step during callback is inert. This rule intentionally differs from unpublished geometry ownership and avoids introducing irrelevant disposal machinery.
4. coverForBounds validates finite ordered bounds and finite nonnegative padM, expands in world units, rejects overflow. Clamp bucket enumeration to index overall bounds; empty or far-outside queries return empty lists without enormous coordinate loops. Gather candidates only from intersecting buckets, apply inclusive feature AABB intersection with expanded query, deduplicate per layer, return numeric ascending original indices. Do not read CityData or rescan source points during queries. AABB conservative false positives at corners are permitted. Query result arrays are fresh, never aliases of bucket lists. Query loop is selection, not an emission timing guarantee; R6 will measure full-view selection separately.
5. Boundary continuity: a polygon surrounding the query with every polygon vertex outside must be selected. A road crossing the query with both endpoints outside must be selected. Queries across adjacent cells must each include a crossing record; combined query returns it once. Cover exists in cells without building owners. Index creation/query must be deterministic and keep exact original indices for later full-data water/crossing/RNG semantics.
